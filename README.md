# Atividade API React

Projeto React + Vite para consumo da PokéAPI usando Fetch e Axios.

## Executar

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

O projeto já está configurado para GitHub Pages com a base `/Atividade-api-REACT/`.
