# Atividade - Consumo de API

Projeto desenvolvido com React para consumir a PokéAPI.

## Tecnologias

- React
- Fetch
- Axios
- Vite

## Funcionalidades

- Busca de Pokémon ao carregar a página
- Estado de carregamento
- Tratamento de erro
- Exibição dos dados
- Botão para buscar outro Pokémon
- Implementação com Fetch
- Implementação com Axios

## Como executar

```bash
npm install
npm run dev
```
